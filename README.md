des jeux de role.

Le projet demarre par sa fondation PostgreSQL. Consultez
[`database/README.md`](./database/README.md) pour lancer la base locale et
appliquer le schema initial.

Le modele conceptuel reste disponible dans
[`docs/data-model.dbml`](./docs/data-model.dbml).
